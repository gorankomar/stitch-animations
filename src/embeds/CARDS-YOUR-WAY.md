## Motion and lifecycle

Four independent outer reveal wrappers use canonical Hard Reveal bottom-to-top, opacity unchanged. Card, Pending, Complete, face start at 0/340/680/1020ms; each uses `--motion-duration-default`, verified in Global Styles as 770ms. Final arrival is 1.79s. Face loop starts immediately after the final entrance. Updated reference: https://www.instagram.com/reel/DQAKER4jGdY/ (refinedmotion_ Apple Face ID After Effects recreation), watched in-browser; Lottie search was inspected but no Lottie asset adopted. The enhanced sequence is a brief anticipatory blink, facial acquisition/turn, four original corners morphing into a complete circular rim, four complete colored circles tilting independently in 3D, with separately shaded front/back arcs, circles aligning into one blue ring, check drawing with a small confirmation pulse, success hold, rim returning to the original corners and facial features. Period is six default durations (4.62s). The morph samples the actual original four SVG subpaths rather than replacing the Figma fallback. The original face remains untouched; generated geometry is a transient runtime enhancement in the existing SVG. `cards-your-way-face-motion.js` owns this enhancement and removes it on disposal/failure. It has no external library, raster, filter, IDs or CSS dependency. Opacity is interpolated linearly; morph, blink, acquisition movement, alignment and check drawing use the primary curve read from Global Styles, verified `cubic-bezier(.11,.61,.27,.99)`. The scanning rings use analytical orthographic projection of complete circles, with independent multi-axis rotations driven by the existing constant-rate phase and eased acquisition/alignment. The corner-derived blue circle forms ring one; sky blue #56B9FF, violet #6E7BEF and mint #43CDB2 form three additional circles of the same radius. Colored rings enter during the corner-to-circle morph at phase 1.3; the corner-derived blue ring begins rotation at phase 1.6. All planes align by phase 2.75 and the colored paths fade, leaving the original blue confirmation ring. The original beginning, checkmark, return timing and existing 72px design footprint are retained. This is a vector approximation of the reference, not an exact After Effects render.

Pointer Follow owns nested label wrappers only. Pending depth 30/max 24 design pixels; Complete depth 10/max 12 design pixels. These reproduce the existing foreground/background relationship with gentler proportional travel. Card stays still. Follow and Dots Field activate after label entrance, only while visible, document active, fine pointer available and reduced motion disabled. Resize remeasures reveal geometry and scales travel/dot spacing. Animation Stage pauses the loop offscreen and in hidden tabs. Reduced motion restores all four elements and face fallback. Missing tokens/DOM, setup or rendering failure, cleanup and motion import failure preserve/restore static artwork. Stage initializer guards duplicate mounts and supports multiple instances.
