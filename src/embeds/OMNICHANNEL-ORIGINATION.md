## Requested motion

- Root `[data-omnichannel-origination]`, tracks `[data-oo-track]`, sequences `[data-oo-sequence]`, rings `[data-oo-ring]`, entrance `[data-oo-reveal]`, follower `[data-follow-mouse]`.
- Rows move left/right/left with linear easing and seamless generated sequence copies. One lap includes sequence width plus the native inter-sequence gap. Durations use Global Styles default token ×36/44/40 (27.72/33.88/30.8 seconds at the inspected default). Re-measure/rebuild on parent resize.
- Three rings share a phase-separated cycle (default duration ×24, 18.48 seconds at 770ms). Visible diameters grow from 170 to 386 Figma units, so the smallest ring extends beyond the foreground card immediately. Phase starts are .03, .3633 and .6967; all three begin at full motion opacity. A shared monotonic radial mapping `170 + 216 × (.8p + .2p²)` gives outer rings a slightly faster expansion without allowing overtaking. Linear keyframe interpolation and short linear birth/death fades keep at least two rings visible throughout. Native fallback retains original 310/238/170 geometry.
- Card entrance: measured translation from beyond the frame bottom to its native centered position, default duration 770ms. Opacity remains 1. Uses `.oo-reveal` independently of layout `.oo-position` and Pointer Follow `.oo-follow`; does not use the globally hidden `[data-reveal]` state.
- Pointer Follow reuses `src/lib/effects/follow-group.js`, strength .05 and its existing travel/return behavior. Root is the entire illustration; only the card follows. This retains the existing cataloged inertia effect.
- Global Styles embed inspected live: `--motion-ease-primary: cubic-bezier(.11,.61,.27,.99)`; `--motion-duration-default:770ms`; fast token is default ×.6. Runtime reads actual token values; it leaves the illustration static if they are absent/invalid. No per-component token redeclaration in Webflow.
- Lifecycle: shared stageInitializer duplicate guard plus global `Symbol.for('stitch.omnichannel-origination.init')` registry for repeated portable/shared bundle loads. IntersectionObserver threshold .1, hidden-tab pause, ResizeObserver, reduced-motion restoration, generated-node removal, animation cancellation, follow disposal and complete cleanup. Entrance is removed from the animation registry after completion to avoid replay when visibility changes. Partial setup failure rolls back to static content.
- Shared entries register the module; Vite includes `feature-omnichannel-origination`. The Webflow draft uses the portable component embed, so this draft needs no loader URL change. Future shared release must preserve the same global mount guard.
