- Static layout, typography, backgrounds, gradients, borders, shadows and SVG transforms are native Webflow styles. Text inherits the site's Body font, Abcdiatype. The script embed uses native `rf-motion-embed` display:none to avoid a Designer placeholder adding height.
- All geometry uses the outer measuring container's cqi units; the frame retains 540:278. No nested query containers. Background content below the original frame stays clipped as in Figma.
- Original assets: branch (30.6294 × 276), plus (20 × 20), three line exports (13 × 1). External SVG images are sufficient because movement belongs to HTML wrappers. No existing plain Plus icon was found across the site icon inventory; Plus Circle has a different shape. Original vector geometry is unchanged, and no optimization derivative is claimed (SVGO was unavailable in the installed dependencies). The two Plus placements share one uploaded asset.
- Root `[data-rules-flow]`; canonical `[data-reveal]` targets use a scoped static fallback so Global Styles do not permanently hide the illustration. Background panel reveals first; its logical units and their text stagger in DOM order. Then `.rf-front-entrance` uses Hard Reveal from right to left, followed by Condition 1, Amount, is greater than, and USD 900.00 in order. One entrance per mount; no idle loop.
- Cataloged effects: Reveal tracks, Animation Stage, Pointer Follow. Defaults verified from live Global Styles on 2026-10-04: `--motion-ease-primary: cubic-bezier(.11,.61,.27,.99)`, `--motion-duration-default:770ms`, `--reveal-stagger-default:200ms`, `--reveal-opacity-ratio:.34`, `--reveal-offset-default:7rem`. Movement follows the primary curve, opacity uses raw linear progress. Offset and default single-follower travel scale with the illustration's width. Hard Reveal preserves opacity and clears the frame, including shadow bleed.
- Transform ownership: fixed `.rf-front-position` layout → `.rf-front-entrance` Reveal → `.rf-front` Pointer Follow. SVG rotation belongs only to SVG image nodes. Fine-pointer follow starts once the foreground box has entered; it stops offscreen, on hidden tabs, and for reduced motion.
- `init(root)` returns cleanup, guards duplicate mounts via stageInitializer and a shared Symbol registry, supports independent instances and remeasures on resize. Setup/render failure restores static transforms/opacities. Reduced motion renders the complete static illustration immediately. Static styling has no external animation CSS dependency.
